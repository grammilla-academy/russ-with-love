# Russ with Love

Статический личный сайт преподавателя русского языка Любы. Отдельный проект; исходники приложения Grammilla и существующие сайты не изменены.

## Адрес и статус

Планируемый адрес: https://grammilla-academy.github.io/russ-with-love/

На 23 ноября 2026 сайт подготовлен и проверен локально. После входа владельца подтверждён аккаунт grammilla-academy; повторная проверка с авторизацией показала отсутствие russ-with-love. Создан отдельный публичный репозиторий https://github.com/grammilla-academy/russ-with-love . Развёртывание Pages ещё предстоит проверить; не считать наличие репозитория подтверждением публикации.

## Исходники

- `content.json` — все тексты EN/IT/RU, включая переводы и фрагменты отзывов.
- `build.py` — генерирует HTML, sitemap и robots без зависимостей.
- `site.css` — общие адаптивные стили.
- `index.html`, `it/index.html`, `ru/index.html` — готовые страницы; английская версия в корне.
- `privacy.html`, `it/privacy.html`, `ru/privacy.html` — отдельное описание фактической работы сайта, не изменение политики приложения.
- `assets/` — оптимизированное фото, Open Graph и favicon.
- `prepare_images.py` — однократная оптимизация предоставленного фото; требует уже установленный Pillow.
- `validate.py` — проверка локальных ссылок, контента, SEO и изображений; требует Pillow.
- `originals/`, `qa/` — только локально, исключены из Git. Оригинальный PNG дополнительно сохранён в originals, исходные файлы пользователя не изменены.

Изменять content.json и site.css, затем выполнять:

```powershell
python build.py
python validate.py
python -m http.server 51423 --bind 127.0.0.1
```

Открыть http://127.0.0.1:51423/ и проверить EN, IT, RU, цены, письмо и мобильный экран. Письмо открывается в настроенном почтовом клиенте; сайт не отправляет его самостоятельно.

## Источники и решения

Основные тексты: предоставленный пользователем запрос с авторским английским текстом Любы. Весь основной английский текст сохранён, добавлены заголовки и переводы.

Дополнительные источники: `C:\Denis files\Мои личные проекты\сайт Любы\Individual\individual_4.png`, `individual_5.png`, `Groups\Group5.png`, `Group6.png`, `Group7.png`; просмотрены все материалы Individual и Groups. Использованы фрагменты Azra, Carolina и Corinne из recenzioni. Переводы EN/IT для Azra и Carolina предоставлены на скриншотах; русский перевод и итальянский перевод Corinne подготовлены для сайта. Подписи указывают язык оригинала/перевода. Остальные отзывы не опубликованы, фотографии учеников не использованы, рейтинги не добавлены.

Пользователь подтвердил в чате: время по Италии (Europe/Rome); можно публиковать отзывы с именами; запись по email. Формат для двоих и его пакеты подтверждены Group6–7. Пакеты считаются в астрономических часах: 6 × 80 минут = 8 часов; 15 × 80 минут = 20 часов. Группа: 10 × 90 минут = 15 часов, €225 с человека, €22,50 за занятие. Случайную строку о 60-минутных группах не переносили. Правило переноса за 24 часа применяется только к индивидуальным занятиям.

Референс изучен: https://russianlangcoach.com/ — последовательность знакомства, подхода, форматов, цен и контакта. Тексты, цены, отзывы, биография и изображения оттуда не копировались.

Актуальная политика https://grammilla-academy.github.io/privacy/privacy.html проверена 23.11.2026: описывает приложение, связанные сервисы и аналитику сайта Grammilla, не выделяет сайт Любы. Не изменена. Новый сайт не загружает аналитику, сторонние шрифты, плееры или соцсети; cookies/localStorage не используются. GitHub обрабатывает технические данные хостинга. Для полноценной юридической проверки email-процессов и реквизитов понадобится участие владельца, не следует дописывать неподтверждённые сроки хранения или юридическое имя.

## Безопасное первое размещение на GitHub Pages

1. Войти в GitHub через Git Credential Manager; не передавать токены в чат или файлы. Проверить авторизованный аккаунт и права в grammilla-academy.
2. Снова проверить наличие `grammilla-academy/russ-with-love`. Если он существует, сначала клонировать/fetch и сверить содержимое; объединить изменения, сохранив удалённые правки.
3. Если отсутствует, создать отдельный публичный репозиторий `russ-with-love`, без изменения privacy и grammilla-support.
4. Поместить эти файлы в корень отдельного репозитория. Не публиковать originals, qa, токены или другие файлы из проекта приложения.
5. Использовать обычные commit/push, никаких force-push. В Settings → Pages выбрать Deploy from a branch → main → /(root). `.nojekyll` уже подготовлен. Обязательная сборка на сервере не нужна.
6. Дождаться успешного Pages deployment. Проверить публичные /, /it/, /ru/, изображения, privacy.html, sitemap.xml, canonical и языковые ссылки; полученный HTTP 200 с содержимым сайта, а не только принятую команду push.
7. Синхронизировать локальную копию с опубликованным commit и записать SHA и дату в этом README.

## Дальнейшие изменения

Перед каждым редактированием: проверить git status, сохранить локальные изменения, затем `git fetch origin` и `git pull --ff-only`. Если локальная ветка разошлась с удалённой — разобрать расхождения; не перезаписывать новые правки других помощников. После обновления выполнить сборку/валидацию, визуальную проверку, commit/push и дождаться Pages deployment. Локальная копия должна соответствовать опубликованному SHA.

## Поиск и SEO

У каждой страницы собственные title/description, self-canonical, взаимные hreflang EN/IT/RU и x-default на английский корень; Open Graph использует полное фото без обрезки лица. JSON-LD содержит Person, WebSite и WebPage, без фиктивных оценок, цен и квалификаций. FAQ составлен из подтверждённых условий; расширенные результаты поиска не обещаются.

Используются только подтверждённые услуги Любы; чужие цены не заимствованы.

Важное ограничение GitHub Pages: `robots.txt` в подпапке `/russ-with-love/` не управляет сканированием всего хоста. Поисковые роботы читают robots в корне `https://grammilla-academy.github.io/robots.txt`. Не создавать и не менять корневой репозиторий без отдельного решения. Карта сайта с правильными URL готова; её можно отправить напрямую.

После публикации, по одному шагу с владельцем:

1. Google Search Console: добавить URL-prefix property `https://grammilla-academy.github.io/russ-with-love/`; выбрать HTML-файл или meta tag. Получить выданный владельцу файл/код и разместить, не придумывая verification token. Подтвердить владение в интерфейсе и отправить `sitemap.xml`. Domain property для github.io без управления DNS не использовать.
2. Bing Webmaster Tools: импортировать подтверждённый ресурс Search Console либо добавить URL и его реальный verification token/файл; после подтверждения отправить sitemap. Пока не выполнено: доступа к этим аккаунтам нет.
